### OrbitX — Enterprise Datacenter Monitoring

Plataforma de monitoramento de datacenters sustentáveis com IA integrada.

**Features:**
- Real-time alerts + satellite orbital tracking
- Machine learning forecasting (LLaMA/Groq) para detecção de superaquecimento
- Assistente IA com RAG para consultas de infraestrutura
- Arquitetura escalável com RabbitMQ para event streaming

**Stack:** `Java` · `Spring Boot` · `Oracle` · `RabbitMQ` · `LLaMA/Groq`

### Bitcoin × S&P 500 — Technical Analysis Dashboard

Análise multiativos comparando S&P 500 e Bitcoin com indicadores técnicos profissionais.
